# Millersville University Library Directory Redesign

## Overview
Redesigned and rebuilt the Library Directory and Subject Librarian Finder for the Millersville University Library main page.

## Features
- Responsive 4-column staff grid layout
- Subject Librarian search tool (input + dropdown mapping)
- Dynamic result preview panel
- Accessibility improvements (WAVE-compliant heading structure)
- Scoped CSS architecture to prevent LibGuides theme conflicts
- Toggle filter between All Staff and Subject Librarians
- DOM sorting by last name

## Technologies Used
- HTML5
- CSS3 (Scoped component styling)
- Vanilla JavaScript
- Accessibility optimization (WCAG)
- LibGuides CMS integration

## Key Improvements
- Improved discoverability of subject librarians
- Removed structural accessibility errors
- Eliminated breadcrumb/header conflicts
- Ensured responsive behavior across devices

Web Developer – Millersville University Library
